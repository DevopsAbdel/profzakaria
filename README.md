# موقع الأستاذ زكريا | Professeur Zakaria

موقع ثابت (HTML/CSS/JS) جاهز لـ GitHub Pages، ثنائي اللغة (عربي RTL / Français).

## النشر
1. ارفع كل محتوى هذا المجلد إلى جذر المستودع (فرع `main`).
2. GitHub ← Settings ← Pages ← Source: *Deploy from a branch* ← Branch: `main` / `/ (root)`.
3. الرابط: https://devopsabdel.github.io/profzakaria/

## التخصيص
عدّل `config.js` فقط: واتساب، البريد، روابط المنصات، فيديوهات يوتيوب، روابط الموارد، ونقطة Formspree.
أي حقل فارغ يُخفى تلقائيًا ولا يظهر في الموقع.
